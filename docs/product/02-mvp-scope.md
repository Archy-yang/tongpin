# MVP 范围界定

> 原则：MVP 验证两个核心命题——①AI 能从对话中提炼出用户认可的画像；②风格匹配能否引发真人对话。凡是与这两个命题无关的，一律后置。

## P0 — MVP（第一阶段交付）

| 模块 | 范围 | 不做什么 |
|---|---|---|
| 用户系统 | 注册、登录（手机号/设备匿名）、匿名昵称、基础设置（年龄段、城市、性别、性别偏好） | 实名认证（合规阶段再做）、头像（MVP 无照片社交） |
| AI 陪伴聊天 | 文本聊天，AI 有基础人格，可记忆上下文（会话内 + 长期记忆摘要） | 语音、图片、多 AI 人格选择 |
| 风格分析器 | 异步任务，定期根据新对话增量更新风格卡 JSON | 每轮实时分析 |
| 风格卡 | 用户可查看、编辑、确认、删除 | — |
| 匹配池 | 用户主动 opt-in，填写关系意图与硬条件 | 被动拉人入池 |
| 基础匹配 | 硬条件过滤 + 风格向量相似度 + 排序，给出契合提示 | 双 AI 暖场、自动开聊 |
| 同意与撤回 | 真人接触需双方同意；授权可随时撤回；撤回后 24h 内数据停止用于匹配 | — |
| 举报与安全 | 举报、拉黑、接入内容审核、AI 标识（所有 AI 会话明确标注） | 未成年人深度保护机制（合规阶段完善） |

**MVP 明确不包含（易混淆项）：**

- ❌ AI 暖场 / 双 AI 代理对话 → P1（DeepSeek 初版文档将此项放在 P0，与里程碑矛盾，此处统一修正为 P1）
- ❌ 真人聊天功能 → 匹配契合提示后，MVP 阶段先验证"提示点击率"，真人聊天在双方同意后进入简单的一对一文本会话即可（最小实现）
- ❌ 付费订阅 → P1

## P1（第二阶段）

1. AI 暖场：双方授权后，两个 AI 代理聊 3-5 轮，生成破冰摘要（共同点 / 可聊话题 / 雷点提醒 / 开场建议）
2. 聊后反馈评分，反哺匹配模型
3. 语音聊天
4. 关系阶段引导（破冰 → 熟悉 → 深度话题）
5. 付费订阅：深度风格分析、优先匹配
6. 合规完善：实名认证、未成年人保护、算法备案对接

## P2（远期）

- 群组匹配
- 线下活动推荐
- 关系教练 AI

## 关键设计决策记录

| 决策 | 结论 | 理由 |
|---|---|---|
| 风格卡可编辑 vs 画像真实性 | **编辑只影响展示层；匹配层使用原始分析画像 + 置信度** | 若用户可随意编辑匹配用的画像，风格匹配退化为自我陈述，差异化消失 |
| 冷启动 | 匹配池 < 500 活跃用户时，契合提示功能灰度关闭，只显示"画像已就绪，等待与你同频的人" | 避免稀疏匹配伤害体验 |
| 风格分析触发 | 每累计 N 条新消息（如 20 条）或每 24h 触发一次增量分析 | 控制推理成本 |
| MVP 真人聊天形态 | 一对一纯文本，无已读、无阅后即焚等花哨功能 | 最小实现，验证转化 |
