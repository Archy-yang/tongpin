# 账号信任分层 + UI 改版落地（2026-10-18）

> 两件事一体两面：**软引导拉注册，硬门槛保真人**；UI 按 `design/h5-redesign.html` 定稿方向反灌。
> 原则：AI 聊天匿名随便聊（漏斗，额度锁死成本）；真人接触与支付高门槛（伤害与资金面）。

## A. 账号信任分层

- [x] **A1 匹配池硬门槛**：opt-in 要求已绑定邮箱。
  match 域新增消费方接口 `AccountGate{HasEmail}`，装配层适配 auth；未绑定返回业务错误
  「先绑定邮箱再进入匹配池」，前端在遇见页给出去「我的」的引导。
- [x] **A2 IP 限流防批量造号**：匿名注册（设备新账号）按 IP 每日限 N 个（默认 10，
  `SIGNUP_IP_DAILY_LIMIT`，≤0 关闭便于测试）。已注册邮箱登录不受影响。
  新表 `signup_rate(ip, day, count)`（迁移 0014）。
- [x] **A3 绑定邮箱 = 额度激励**：绑定成功将 `users.free_quota` 设为
  `BOUND_DAILY_MSG_QUOTA`（默认 15）。前端文案「绑定成功，每天可聊 15 条了」。
  匿名默认仍是全局 10 条——限制变成正向激励。
- [x] **A4 软引导时机**（前端为主）：
  - 同频卡就绪页：未绑定邮箱时提示「绑定邮箱，换设备也不丢这张卡 → 我的」；
  - 支付前强制绑定：`POST /billing/checkout` 校验 HasEmail，未绑定返回
    「购买前先绑定邮箱」（billing 域同款消费方接口，适配 auth）；
  - 「我的」页绑定成功文案更新为额度激励。

## B. UI 改版落地（design/h5-redesign.html → Vue）

- [x] **B1 style.css**：新 tokens（night 渐变 / lamp / moon / note 纸 / 发丝线）、
  按钮 :active 回缩、细滚动条、reduced-motion 保留。
- [x] **B2 App.vue**：tabbar 重做（SVG 线性图标 + active 灯条 + 毛玻璃底），
  router-view 160ms 淡入过渡。
- [x] **B3 ChatView**：页头改「时段小字 + 灯点」；用户气泡 → 暖纸便签（夜里唯一亮的纸）；
  AI 三点打字指示器（发消息后出现，回复到达消失）；消息入场动画；textarea 自动长高。
- [x] **B4 StyleView**：kv 双栏卡、话题 chips、新页头（版本/把握 → 时段落）。
- [x] **B5 MeetView**：契合卡（hl 列表灯点符号）、开场建议引用样式、双按钮组。
- [x] **B6 DmView**：真人气泡体系（对方=暗面板泡，我=暖纸泡——与 AI 聊天同语言），
  WS 状态改灯点。
- [x] **B7 MeView**：三卡（账号/会员/设置）新样式 + A3/A4 文案。
- [x] **B8 验证**：vite build + 浏览器全页走查（含发消息、tab 切换、绑定流程），
  Docker 预览栈重建镜像同步新 UI。

## 验收

- 匿名用户：能聊（10 条/天）、能看卡；进匹配池被引导绑邮箱；checkout 被拦；
- 绑定后：额度变 15、能进匹配池、能到 checkout；
- 同 IP 连续造 11 个新设备账号：第 11 个被拒（限流可配）；
- UI：六视图与新设计稿一致，交互（打字指示器/入场/tab 过渡）可用。
