# 风险与对策

## 产品风险

| 风险 | 等级 | 对策 |
|---|---|---|
| 风格分析产出不被用户认可（产品心脏不跳） | 高 | 阶段 0 Spike 前置验证；不通过即止损，不投入后面 8 周 |
| 风格相似 ≠ 真人聊得来 | 高 | 风格只是主信号之一（权重 0.45），叠加意图、地理、活跃时段；聊后反馈（P1）持续修正 |
| 冷启动匹配池过稀 | 高 | 先单边陪伴攒池；< 500 活跃用户时契合提示灰度关闭 |
| 用户停留在陪伴层不进匹配池 | 中 | 不强推（产品原则）；商业模型上陪伴层本身是留存基本盘，匹配转化率是 P1 优化对象 |
| 前 500 种子用户从哪来 | 高 | 未解。候选：小红书/豆瓣兴趣社区内容获客、朋友圈口碑、AI 陪伴话题自带传播性。内测期先靠人肉邀请，验证产品价值后再谈增长 |
| LLM 推理成本失控 | 中 | 风格分析异步批量 + 便宜模型；聊天设每日免费条数；成本监控告警 |

## 合规风险（国内）

| 风险 | 对策 |
|---|---|
| 陌生人社交/婚恋类监管（实名制要求） | 架构上"匿名对外、实名对平台"：用户可见层匿名，平台层手机号实名（阶段 3 接入） |
| 生成式 AI 备案 | 使用已备案的第三方大模型 API（DeepSeek/GLM 等），自身以应用层身份评估是否需备案，上线前咨询 |
| 未成年人保护 | 注册时年龄段采集 + 拦截；成人内容审核管道；阶段 3 完善 |
| 个人信息保护法 | 风格数据最小化采集（白名单字段）、可删除（物理删除）、可撤回（授权审计），架构已内置 |

## 技术风险

| 风险 | 对策 |
|---|---|
| LLM 输出不稳定（JSON 解析失败） | Prompt 强约束 + 解析失败自动重试 + 字段白名单校验，失败入库人工抽检 |
| 风格分析被恶意对话污染（用户故意输入极端内容操纵画像） | 敏感内容不入画像（Prompt 层禁止 + 存储层校验）；画像更新幅度限流（单次更新维度变化上限） |
| 内容安全事件 | 接入成熟审核服务商，不上线自研审核；AI 会话与真人会话都过审 |
| 单点部署故障 | Docker Compose + 每日备份；MVP 阶段接受单机风险 |

## 止损点

- 阶段 0 不通过 → 重新评估方向，最多迭代 2 轮 Prompt
- 内测 4 周 7 日留存 < 10% 且风格卡认同率 < 40% → 停止功能开发，回到用户访谈找原因
